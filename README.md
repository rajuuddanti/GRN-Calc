# GRN Veg Cost Calculator — Android source project

Offline-first native Android app for vegetable purchase costing. Includes the GRN launcher icon.

## Included
- Android Studio project files (Gradle configuration, manifest, theme, Java source).
- Five starter products: Alugadda, Ulligadda W, Ulligadda R, Allam, Yelligadda.
- Editable additional SKU rows and quantity/cost/amount calculations.
- Expense allocation and final cost-per-quantity calculation.
- Local offline draft saving and purchase history.
- GRN launcher icon resources.

## Open/build
1. Extract the ZIP.
2. Open the `MahaMartVegCostCalculator` folder in Android Studio.
3. Let Gradle sync, then build/run the app.

This is the full source project, not a prebuilt APK. It has not been compiled or device-tested in this environment.
